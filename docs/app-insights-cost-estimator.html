✅ Workbook / Report / Dashboard = ALWAYS FREE

Running KQL queries, viewing Azure Workbook dashboards, refreshing data → never costs money. Costs only come from ingestion (sending data up) and retention (keeping data beyond 90 days). Viewing reports is completely free, no matter how many times.

💡 Tips to keep cost = $0 forever

Go to Usage and estimated costs → Data Retention = 90 days. Data older than 90 days will be auto-deleted. As long as monthly ingestion stays under 5 GB, everything is completely free.

⚠️ After 2 years of operation — what should you do?

Option A: Keep Retention = 90 days → no storage cost, old data auto-deletes.
Option B: Export data to CSV (free) or Azure Blob before the 90-day window expires, then delete old data.
Option C: If you need to keep data > 90 days → use Archive tier ($0.02/GB/month) for compliance.
Option D: Create a new App Insights resource, start fresh (free tier resets).
