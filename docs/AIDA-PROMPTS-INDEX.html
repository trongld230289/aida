Các prompt AIDA đang dùng

Mỗi dòng hiển thị vài chữ đầu của prompt, đúng y như trong code. Copy đoạn đó rồi tìm bằng Ctrl+Shift+F, hoặc copy path:line rồi dán vào Ctrl+P để mở file đúng dòng.

Đường dẫn tính từ thư mục gốc của extension aida/.

Chế độ CopilotKhông có role system. Mọi prompt được gửi dưới dạng tin nhắn User.
Chế độ API keyCó role system. Review và dependency dùng chung một câu system prompt, còn chatbot dùng system_prompt.md.
Template reviewreview-*.md + review-base.md (ghép vào chỗ {{REVIEW_BASE}}), sau đó nối thêm diff hoặc nội dung file.
Rà từ source ngày 27/11/2026. Nếu prompt bị đổi trong code, nhớ cập nhật mảng DATA trong file này.
